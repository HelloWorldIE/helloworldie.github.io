    HelloWorld helloworld.ie (opens in a new tab) This page keeps no project data. It reads GitHub with your own access.

    Sign in

    Signed out, the hub shows public projects only. Sign in to see every project your account can read.

    The hub can only read your repos, never change them. Staying signed in lasts until you sign out, or six months without a visit. On a shared computer, clear the box: the sign-in then ends when you close the tab.

    Or use a read-only token
    1. Select Create a token. GitHub opens with the name, a 90-day expiry and read-only access to contents already set.
    2. Under Repository access, select All repositories.
    3. Select Generate token, copy the token and paste it here.

    The token stays in this browser tab and goes only to GitHub. Closing the tab signs you out. Use a read-only token: the hub never needs to change anything.
